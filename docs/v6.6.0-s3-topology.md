# v6.6.0 · Полные фазовые волокна на S³

Атлас показывает обе полные фазовые линии Φ=0 и Φ=π на Clifford-торе
в единичной трёхмерной сфере. Cyan и coral обозначают две разные фазы;
каждая фаза может состоять из нескольких связных компонент. В режиме
«Трисфера S³» раскройте карточку `T(p,q)` и включите волокна, либо выберите
пресет Hopf, (2,2), Trefoil, (3,4) или (4,6).

## Математическая модель

Для z₁=cosη exp(iα), z₂=sinη exp(iβ) используется фазовая функция
Φ=qα−pβ mod 2π. При d=НОД(|p|,|q|) компонента k задаётся

```
α(t) = (p/d)t
β(t) = (q/d)t + (2πk − Φ)/p,   k=0,…,d−1,   0≤t≤2π.
```

Таким образом, у одного полного фазового волокна ровно d компонент,
каждая имеет сокращённые числа обходов (p/d,q/d). Завершение полигона
повторяет его первую точку точно. Стереографическая проекция из
(0,0,0,1) имеет вид `(x₁,x₂,x₃)/(1−x₄)`; полюс возвращает отказ, а не
искусственно ограниченный знаменатель.

Для двух разных полных волокон теория предсказывает полное ориентированное
зацепление pq. Зацепление одной пары компонент равно pq/d². Например,
(2,2) содержит две компоненты **на каждой фазе**, четыре межфазные пары
с Lk=1 и суммарно Qlink=4. (2,3) содержит по одному трилистнику и
суммарное межфазное зацепление 6. Число компонент, узловой тип и взаимное
зацепление — разные свойства.

Знак соответствует стандартному интегралу Гаусса
`∮∮ ((dr₁×dr₂)·(r₁−r₂))/|r₁−r₂|³ /(4π)` и указанной ориентации t.
Изменение ориентации одного волокна меняет знак. Ядро поддерживает
отрицательные p/q; интерфейс следует положительным числам обходов
существующих регуляторов, от 1 до 8.

## Независимая численная проверка

Кнопка «Проверить численно» интегрирует ориентированные телесные углы
для всех пар полигональных компонент. Используется устойчивая
триангуляция сферического четырёхугольника разностей концов отрезков
и компенсированное суммирование. Возвращается вычисленное число, без
округления до ожидаемого целого. Расчёт повторяется на сетках N и 2N;
карточка показывает невязку и разрешение, JSON — также матрицу пар,
расхождение двух сеток, минимальное расстояние между полигонами и метод.

Открытые, вырожденные, пересекающиеся и численно неразрешимые полигоны
получают отказ. Эти проверки относятся к представленным полигонам;
две сетки дают свидетельство устойчивости дискретизации, но не являются
универсальным доказательством отсутствия особенностей у любого
неизвестного непрерывного поля.

Геометрия является **эталоном фазовых волокон**. Qlink=pq здесь не выдаётся
за Hopf-инвариант, измеренный из импортированного магнитного/акустического
поля. Волновое уравнение и микромагнитный решатель не добавлены.

## Проверенные первичные источники

Доступ и поиск: 2026-10-03. Статус перечисленных работ — препринт;
рецензирование не предполагается по одному наличию в arXiv.

- [Acoustic toroidal vortices with programmable links and knots](https://arxiv.org/abs/2608.15499),
  2026-08-16. PDF, уравнения (7)–(11): фазовые линии, pq, НОД и суммирование
  зацепления всех компонент. Это непосредственная основа новой геометрии.
- [Weaving Hopfions from Emergent Monopoles in a Chiral Magnet](https://arxiv.org/abs/2608.24116),
  2026-08-25. Проверено определение Hopf-числа через зацепление прообразов
  и зависимость знака от направления. Работа задаёт научный контекст;
  её микромагнитная динамика не воспроизводится этим модулем.
- [Magnetic hopfions at room temperature](https://arxiv.org/abs/2607.26839),
  2026-07-29. Проверено различие общих топологических зарядов при конусных
  граничных условиях и обычного Hopf-индекса: геометрический pq нельзя
  автоматически присваивать произвольному физическому полю.

## Воспроизводимость выпуска

Ранее workflow строил `build/index.html` из `app-v4.5.0.html` и терял модули
v5.5, v6.2, v6.5 и все дальнейшие. Теперь

```
node --test tests/*.test.mjs
node tools/verify-atlas.mjs --output build
```

проверяет исходный современный `index.html`, компиляцию всех inline scripts,
обязательные научные модули и точное совпадение compressed XR input с текущим
renderer, затем копирует файл побайтно. JSON отчёт содержит SHA-256 входа и
выхода. Исторические `consolidate-v46.mjs` и hotfix-builder сохранены для
воспроизведения старой версии и не являются текущим release pipeline.

Браузерная проверка, при наличии Playwright и Chromium:

```
python -m http.server 8766 --bind 127.0.0.1
ATLAS_URL=http://127.0.0.1:8766 node tests/browser-atlas.cjs
```

VR hardware на Quest 3 требует отдельного прогона на устройстве; проверка
продолжительного permission prompt использует управляемое время в регрессии.
