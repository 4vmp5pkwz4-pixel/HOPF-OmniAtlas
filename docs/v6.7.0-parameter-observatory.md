# Лаборатория параметров · v6.7.0

Шесть исследований доступны по кнопке «Лаборатория» рядом с названием атласа.
Сохраняется объёмная сцена Obsidian Atelier. Новый экран использует её палитру,
но научные графики строятся непосредственно по вычисленным данным.

| Исследование | Вычисление и управление | Граница результата |
| --- | --- | --- |
| Планк | Bν и Bλ; температура; разные положения максимумов; независимая квадратура против σT⁴ | Идеальное равновесное чёрное тело |
| Казимир | Давление, сила, энергия на площадь; зазор, площадь, температура контекста | Бесконечные идеальные проводники, давление при T=0; тепловая поправка не вычисляется |
| Резонансы | Частота и Q; точная нормировка трёх действующих моделей; численная невязка | Линейные сосредоточенные RLC, масса–пружина и резонатор Гельмгольца |
| Фракталы | Бифуркации логистического отображения, x₀, переходный процесс; конечновременной λ; пыль Кантора и подсчёт ячеек | Конечные орбиты и конечный диапазон масштабов не доказывают универсальный хаос или фрактальность |
| Карта модели | Независимая ось × один физический параметр, модуль либо фаза Γ, выбор точки и перенос в S³ | Замороженные остальные параметры; невалидные значения маскируются |
| S³ | Обмотки p,q, все компоненты двух фазовых волокон, переход в объёмный атлас | Геометрический эталон; численная проверка зацепления доступна в основной сцене |

Карта вычисляется порциями и отменяет устаревшие задания. Просмотр карты не
изменяет текущую физическую модель. Явное действие «Открыть в S³» переносит
параметры и рабочую точку; геометрическое представление не подменяет физические
единицы и не превращает форму кривой в доказательство общего механизма.

Экспорт `uprs-experiment/1` содержит версию, выбранное исследование, уравнение,
определения и значения параметров, результаты, координату выбора и источники.
Это воспроизводимый вычислительный эксперимент, не протокол измерения.

## Исправленные научные ошибки

- Графен: пассивная проводимость, Drude-предел и универсальная межзонная
  проводимость e²/(4ℏ); явно указана нулетемпературная межзонная аппроксимация.
- Двойная отрицательная среда: согласованные знаки потерь и отрицательная
  ветвь n=εz при соглашении exp(+iωt).
- Raman: усиление определяется мнимой частью восприимчивости, а фазовый сдвиг — действительной.
- Постоянный Q: сохранена комплексная степень; в пределе без потерь остаётся
  распространение с единичной амплитудой и корректной задержкой.
- Межзвёздная дисперсия: знак спектральной фазы и устранение лишнего множителя
  два; DM=50 при 1 GHz даёт 207.4404 ms.
- Волновод: TE-отсечка — бесконечный импеданс и Γ=+1; TM — нулевой импеданс
  и Γ=−1; затухающая ветвь согласована с временным соглашением.
- Потенциал −∫D₁/D₂ dx уже безразмерен: барьер больше не делится на D₂ повторно.
- CCM ограничен равномерными временными отсчётами/итерациями; добавлено
  исключение соседних временных точек. Результат описывает восстановление
  координат и не объявляет причинность без дополнительных проверок.
- Корреляционная размерность учитывает совпадающие состояния; атомарная
  периодическая выборка не получает выдуманную дробную размерность.
- Открытая дуга больше не получает winding и площадь искусственно замкнутого контура.
- Персистентная топология измеряется в полном пространстве задержанного
  вложения; трёхмерная PCA используется для показа. Усечённый комплекс не
  выдаёт сертифицированный топологический вывод.
- Размерностный анализ распознаёт безразмерную единицу и приставки SI.
  Неизвестные единицы, mol и cd останавливают анализ с объяснением: они не
  отбрасываются молча из используемого пятикомпонентного базиса.

## Источники и вычисления

Определяющие константы h, c, kB заданы точными значениями SI по
[NIST/CODATA](https://physics.nist.gov/cuu/Constants/). Квадратура спектра
использует преобразование x=t² с якобианом, компенсационное суммирование и
сравнение с независимо записанной формулой Стефана–Больцмана.

Казимир: [Klimchitskaya, Mohideen, Mostepanenko, Rev. Mod. Phys. 81 (2009)](https://doi.org/10.1103/RevModPhys.81.1827).
Динамика: [May, Nature 261 (1976)](https://doi.org/10.1038/261459a0).
Самоподобие: [Hutchinson (1981)](https://doi.org/10.1512/iumj.1981.30.30055).
S³: [геометрия и источники v6.6.0](v6.6.0-s3-topology.md).

## Воспроизводимость выпуска

Исходники нового модуля: `_includes/uprs670-laboratory-core.js` и
`_includes/uprs670-laboratory-ui.html`. `tools/sync-laboratory.mjs` вставляет их
побайтно в автономный `index.html`. Проверка выпуска сверяет обе вставки,
синтаксис всех скриптов и идентичность опубликованного XR-модуля.

```
node --test tests/*.test.mjs
node tools/verify-atlas.mjs --output build
python -m http.server 8766 --bind 127.0.0.1
node tests/browser-laboratory.cjs
node tests/browser-atlas.cjs
node tests/browser-atelier.cjs
```

Браузерные проверки используют Chromium/Playwright. Они проверяют числовое
редактирование, все исследования, отмену карты, перенос в атлас, экспорт,
клавиатуру, четыре размера лаборатории и светлую тему. Сохранены отдельные
проверки исходной сцены, перетаскивания, GPU, потери контекста и восстановления.
Физическая проверка на Quest не выполнялась. Подробные результаты выпуска
сохраняются в `v6.7.0-verification.json`.
