# S³ Obsidian Atelier Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Restore the original luxury art direction with a volumetric, interactive S³ sculpture.

**Architecture:** A self-contained WebGL2 module consumes the existing topology centre lines and camera. Pure mesh/projection functions remain separately testable. The native Canvas renderer keeps picking and acts as fallback.

**Tech Stack:** JavaScript, WebGL2/GLSL ES 3, Canvas, Node tests, Chromium/Playwright.

**Spec:** docs/superpowers/specs/2026-10-03-s3-atelier-design.md

## Global Constraints

- Single-file, offline app, no runtime dependencies.
- Exact existing phase-fibre centre lines and Gauss linking remain authoritative.
- Same camera projection and pointer coordinates as Canvas.
- Cache meshes and GPU buffers; bounded pixel budgets.
- Lost/unavailable WebGL restores Canvas; non-S³ modes retain their visual behaviour.

## Review Focus

- Closed mesh seams must not twist or introduce nonfinite normals.
- Small/high-winding curves must not acquire misleading inflated intersections.
- Picking must follow the rendered camera under roll and zoom.
- Context loss must recover without hidden geometry or new animation loops.
- Light/paper themes and narrow viewports must keep labels readable.
